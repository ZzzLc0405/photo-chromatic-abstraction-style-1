# Style-1 visual grammar

## 1. Color hierarchy

- Use 4-7 colors by default and no more than 8, including the separator/background color.
- Give the dominant field approximately 35-70% of the canvas when the source has a clear dominant color.
- Use supporting fields to preserve broad warm/cool order, not pixel-accurate area.
- Merge near-duplicate colors. Increase value or saturation separation only enough to prevent muddiness.
- Delete small, low-impact colors even when they belong to a photographed subject.
- Let the grounding field remain visually heavy when the source has a dark road, interior, foreground, or shadow base.

## 2. Base fields

- Prefer horizontal bands for horizon-led scenes and palette studies.
- Use large rectangles for split walls, large skies, interiors, or broad color masses.
- Use one simple diagonal quadrilateral when direction is essential to the color order.
- Avoid reconstructing object silhouettes with many adjacent blocks.
- Preserve approximate top-to-bottom or left-to-right color order, but adjust field thickness for visual balance.

## 3. Adaptive separation

Use no universal separator rule.

- Let high-contrast fields touch.
- Insert a narrow separator when similar values merge or when a palette sequence needs breathing room.
- Group related fields together and separate groups more clearly when appropriate.
- Prefer one consistent neutral or pale source-derived separator color.
- Keep gaps subordinate. They are rhythm, not outlines.
- Do not wrap every field in a border.

## 4. Accent selection

Rank candidate accent sources across five signals:

1. **Area:** how much visual weight the event occupies.
2. **Contrast:** how strongly its color separates from adjacent fields.
3. **Repetition:** whether it appears as a recognizable group.
4. **Rhythm:** whether its spacing or scale variation organizes the composition.
5. **Position:** whether it stabilizes, interrupts, or redirects the field structure.

Prefer the event with the strongest combined perceptual effect, not the most nameable object or easiest geometry. A tiny cloud should not displace a prominent row of trees merely because circles are convenient. A person or vehicle may disappear completely when its color mass is weak.

When no discrete event survives, modify one major field boundary or use a rare, source-derived color node as the accent.

## 5. Accent count and families

- Count 1-5 visible accent instances.
- Use one family by default: circle/ellipse, rectangle, triangle, trapezoid, or rhombus.
- Treat circles and ellipses as one family.
- Use at most two families, with the second clearly subordinate.
- Repetition of one family is one visual language, not multiple styles.
- Let the source suggest the family. Do not default to circles when rectangles, a triangle, or a boundary event better describes the retained color memory.

## 6. Accent arrangement

- Vary size when representing an organic group such as clouds.
- Use uneven spacing and staggered heights when the source is irregular.
- Allow controlled boundary crossing to connect color zones.
- Avoid centered badges, equal intervals, and identical sizes unless the source contains strict repetition.
- Maintain one relation across the group: shared color, shape, direction, scale progression, or source identity.
- Keep total accent area normally near 5-20% of the canvas.
- Represent a broad source group with several related instances when needed, but keep the total within the 1-5 limit. The group should read as one event.

## 7. Canonical geometry

Allowed:

- Rectangles and bands
- Circles and ellipses
- Triangles
- Trapezoids and simple diagonal quadrilaterals
- Rhombi when the source supplies a repeated diamond motif

Avoid:

- Traced organic contours
- Bézier silhouettes
- Decorative icons
- Thin incidental lines
- Gradients, shadows, textures, transparency, and outlines

## 8. Style boundary

Style 1 is color-first. Style 2 is structure-first.

- If the same geometry can serve another photo after changing colors and one motif, it is plausibly Style 1.
- If exact object placement, scale, overlap, or adjacency must be redesigned for every photo, it is Style 2.
- A Style-1 accent may evoke an object, but it must not rebuild the object's anatomy or full silhouette.
